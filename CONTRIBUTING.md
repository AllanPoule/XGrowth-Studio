# Contribuer à XGrowth Studio / Contributing

## Français

Merci de vouloir contribuer !

Avant qu'une pull request puisse être fusionnée, chaque contributeur doit signer
l'accord de contribution du projet ([CLA.md](CLA.md)). Vous gardez les droits
d'auteur sur votre travail. L'accord autorise le mainteneur à distribuer vos
contributions sous la licence AGPL-3.0 du projet, mais aussi sous d'autres
licences, y compris commerciales.

La signature se fait en un commentaire : à l'ouverture de votre première pull
request, le bot **CLA Assistant** vous demande de publier ce commentaire :

```
I have read the CLA Document and I hereby sign the CLA
```

Une seule signature suffit pour toutes vos contributions.

## English

Thanks for your interest in contributing!

Before a pull request can be merged, every contributor must sign the project's
Contributor License Agreement ([CLA.md](CLA.md)). You keep the copyright in your
work. The agreement allows the maintainer to distribute your contributions
under the project's AGPL-3.0 license and also under other licenses, including
commercial ones.

Signing takes one comment: when you open your first pull request, the
**CLA Assistant** bot asks you to post:

```
I have read the CLA Document and I hereby sign the CLA
```

One signature covers all your contributions.

## Bonnes pratiques / Guidelines

- Une pull request = un changement clair. / One pull request = one clear change.
- Décrivez ce qui change et pourquoi. / Describe what changes and why.
- Ne soumettez que du code dont vous avez les droits, et signalez tout code
  tiers et sa licence. / Only submit code you have the right to submit, and
  flag any third-party code and its license.
- Ne commitez jamais de cookies, jetons ou identifiants X. / Never commit X
  cookies, tokens or credentials.
